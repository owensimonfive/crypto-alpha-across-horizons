# Results

This directory contains the small, frozen evidence layer used by the recruiter-facing research package.

## Tables

`tables/` includes selected artifacts such as:

- original failed-validation summary;
- continuation formation / holding / cadence summaries;
- frozen finalist definitions;
- frozen final-holdout protocol;
- pre-2025 reproduction gate;
- untouched final-holdout metrics;
- holdout degradation;
- common-clock finalist correlations;
- cost sensitivity;
- risk and tail statistics;
- monthly breadth;
- market exposure;
- implementation breadth;
- asset concentration.

These are not a replacement for the notebooks. They are compact audit artifacts that make the research record easier to inspect.

## Figures

`figures/` is reserved for a small set of publication-quality graphics generated from the public notebooks.

The repository intentionally avoids copying the full historical figure archive. Only figures that materially support the final research story should appear here.
